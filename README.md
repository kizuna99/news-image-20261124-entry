## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024, deterministic)
```

`main.py` renders the sheet from `data.py` with `render.py` (Pillow) and
falls back to the committed `entry.png` if the drawing stack is missing.
Every story was reported on 23–24 November 2026; `SOURCES.md` lists the
reporting behind each figure — nothing is invented, and claims are marked
as claims, with the counter-claim shown.
